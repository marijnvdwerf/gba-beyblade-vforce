# Particle matching observations

## sub_804E7D4

- Matched exactly with the implementation in `src/particle.c`.
- `scale` and `velocity` must be `s16`; the target uses signed-halfword normalization and arithmetic right shift in the fixed-point products.
- `sequence` must be `s16`; this produces the target `lsl #16; asr #13` sequence-record offset calculation. A wide `unk32` sequence emitted direct `lsl #3` and did not match.
- `offsetX`, `offsetY`, and `offsetZ` remain `unk32`; narrowing them introduced unwanted halfword normalization and changed the frame/register allocation.
- `lifetime` and `timer` remain `unk16`; widening lifetime changed ABI stack offsets and frame shape.
- The chained timer stores (`particle->unk20 = particle->unk22 = timer;`) are byte-identical to the direct-store and parameter-copy forms; no timer temporary is required.
- The natural source order `sprite = particle->sprite; frame = &system->unk0->sequences[sequence];` is required for the target allocation when `sequence` is `s16`.
- The matched function has a 16-byte local frame and exact instruction/pool layout. The dump was removed after verification.

## sub_804E6A4

- Best typed draft is retained in a `#if 0` block immediately above the original `INCLUDE_ASM`; the dump remains active.
- `scale`, `velocity`, `sequence`, and `frameValue` are `s16`; `timer` is `unk16`; these widths remove the explicit frame-value signed cast while preserving the parked draft's intended signed comparison.
- The draft matches the target through the table calculations, particle/frame setup, coordinate math, frame selection, sprite write, and wrap control flow, but differs in natural register allocation at the zero-initialization, coordinate-store temporaries, final frame-pointer test, and wrap-to-zero materialization.
- The first target divergence in the best draft is the zero register used before the three chained zero stores: target `mov r0, #0`, draft reuses an existing zero in `r6`. Later differences are register-role propagation and one trailing literal-pool padding halfword.
- The chained timer stores (`particle->unk20 = particle->unk22 = timer;`) are used directly in the parked draft; the separate timer copy was removed.
- Splitting the chained zero stores and adding a dedicated zero temporary both worsened the emitted schedule; neither was retained.

## sub_804E7D4 coordinate locals

The `x`, `y`, and `z` locals are each byte-required. Folding `x` into the `particle->unk10` expression first diverges at target offset `0x0A` (`sub sp, #16` versus `sub sp, #24`), and folding `y` first diverges at target offset `0x0A` (`sub sp, #16` versus `sub sp, #28`). Folding `z` first preserves the frame size but first diverges at target offset `0x7A` (`asr r4, #8` versus the folded form's `mov r8, r4`). The original three-local form is retained.
