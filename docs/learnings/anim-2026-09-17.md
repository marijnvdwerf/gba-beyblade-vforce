## Animation object layout

- `sub_805F0B4`, `sub_805F47C`, and the three functions below access one animation object: offset `0x08` is a resource-end pointer, offset `0x10` is a table of 0x10-byte frame records, offset `0x42` is a sequence index, and offsets `0x6C`/`0x70` hold the frame callback and its context.
- `allocateRenderCode` independently stores executable code at `RenderCode` offset `0x10`; therefore the animation functions cannot use `RenderCode` for that offset. `AnimFrameState` and `AnimFrameRecord` are defined in `render.h`, while `common.h` has no animation-only definitions.
- `AnimFrameRecord` contains the three words copied by `sub_805F8D4` at offsets `0x00`, `0x04`, and `0x08`, followed by four bytes of padding to establish the 0x10-byte stride.
