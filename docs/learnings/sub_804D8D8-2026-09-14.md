# sub_804D8D8 (0x0804D8D8)

Matched in src/riderphysics.c using canonical RiderBase fields, with no
fakematch, casts on fields, artificial guards, or inline assembly. The caller

the function as reachable. The assembly dump is removed.

## Types and layout

Signed comparisons of the loaded coordinates and signed division after their
reload prove s32 unk40/unk44. Signed halfword loads prove s16 unk50 through
unk5E. unk60 is only stored as a halfword here and remains unk16. unk64, unk68,
and unk8C have only word stores here and remain unk32. New fields replace exact
padding ranges; subsequent field offsets are unchanged. sub_804CB08's two
pointers to unk50/unk52 now use s16* to match those fields.

## Source shape experiments

The original draft reused maxX for the default and selected X limit, and maxY
for the alternate X limit and selected Y limit. The matching implementation
uses separate defaultMaxX, alternateMaxX, maxX, and maxY locals. These represent
loaded configuration and the selected per-axis limits, with distinct lifetimes.

## Fold tests

Each remaining single-use loaded value was folded independently into its use,
with a build and full ROM comparison. All four break the match:

- speedX: first divergence +0xC, loads +0x52 first instead of +0x50.
- speedY: first divergence +0x12, adds 4 instead of 2.
- defaultMaxX: first divergence +0x18, adds 6 instead of 2.
- alternateMaxX: first divergence +0x1A, scratch register changes.

Coordinates and damping results carry evolving state; selected limits and length
are consumed by the calculations. The unused angle staging variable was removed.
