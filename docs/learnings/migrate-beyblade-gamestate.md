#Beyblade gamestate migration

A byte-valued formal parameter can preserve the original low-byte truth test without an explicit shift in source: agbcc emits the entry `lsl #24`/compare sequence when the parameter is tested for nonzero. Keep the parameter narrow when the generated code proves that conversion shape.

For fixed-layout state arrays, declaring the accessed word range as a typed field preserves the field width and avoids cast-and-offset dereferences. When the compiler reassociates a typed field address and an index into a different `add` destination, do not force the match with inline assembly or raw offsets;
leave the inclusion in place until a source - level layout / shape is established.
