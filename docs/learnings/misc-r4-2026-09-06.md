## sub_804393C (0x0804393C)

Matched the packet checksum using the typed `Packet` layout. The checksum starts as the sum of the high and low nibbles of the byte-2 bitfield (`unk2_4` and `unk2_0`), then XORs the twelve payload bytes as signed byte values. A `s32` loop index, payload pointer, and `unk32` accumulator reproduce the target's byte-load sign extension and countdown-free `i <= 0xB` loop. The target's final byte normalization follows from the `unk8` return type. The high-nibble field was added to `Packet`; its fixed size remains 0x10 bytes.

Matched as an item-bit test against `_currentGameState->unk594[arg0 >> 5]`. The `unk594` region is represented as four `unk32` words so the target word load and bit index scale are emitted directly.
