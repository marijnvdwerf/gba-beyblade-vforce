## Layout and types

RiderBase gains unk78/unk7C word fields and the four-component signed unk178
array, replacing padding without changing later offsets. The array is passed to
sub_805A148 and sub_805A1DC, whose signed multiplication and arithmetic shifts
establish signed components. Local vectors use s32 to agree with these helpers;
sub_8059FF8's destination pointer is likewise s32* in its definition and header.
The constructor's instructions remain identical.

unk16C is s32: the target uses asr on its loaded value for the third rotation.
The first negated-angle calculation uses an unsigned mask/local, retaining lsr.
angle1/angle2 can be unk32 because signedness comes from the field shift before
the byte conversion. Scalar table snapshots and height staging values likewise
use unk32; controlled signed-to-unknown changes were byte-neutral.
