# sub_804444C

Matched at 0x0804444C in src/festate.c. Reachable through the frontend handler table; dispatcher passes FrontendState* and an event word. No rule-breaking shapes.

The old disabled draft used packet byte B instead of byte 5 in the 0x08000000 flag branch, omitted a repeated RiderHasFlag call, compared game-state byte 6A5 against 6A4 instead of 6A6, and subtracted the wrong score in the first threshold test. The recovered switch emits cases 0, 1, 2 in that order.

CurrentGameStateTail.unk0 is signed: the target uses asr #8. Ordinary signed shifts by 16 and 24 compile to the target ldsh and ldsb. Explicit union halfword/byte reads instead compiled to ldrh/ldrb before the byte stores; no union is needed. Existing users sub_8043DB8 and sub_8053B94 retain identical instruction diffs. sub_8044314's unused second argument is now Packet*, as passed by this callback; its instruction diff remains identical.

The five RAM words at 030001AC–030001BC are scalar state, not pointers. AC/B0 are signed fixed-point positions (asr #2), and B4 is signed (ble against 0x7E). The flag storage at C0 preserves its original eight-byte extent; the ten sprite pointers at C8 preserve forty bytes.

Temporary folding was checked with the full ROM SHA1 after each trial. Removed otherValue, progress, and flag byte-identically. Folding total or count changes bytes: they stage the 6A5/6A6 loads before the 6A7 score load. The packetData, packetState, record, and data aliases also change bytes when folded. Score value, difference, and halfDifference preserve snapshots across sub_8043960; delta preserves the computed movement across sub_80596AC. Reading -_unk30001B0 for the initial movement produces the required neg instruction, whereas the literal -0x10000 introduces a pool word.

Final clang-format followed by cmake --build build --target compare passes, SHA1 cd527c8c24e20e33913fc45199e64b3e6138a6e5.
