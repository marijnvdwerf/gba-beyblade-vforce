# R2 geometry matching notes

## allocateDynamicBoundingAreas (0x0805BFE8)

The semantic draft is retained in a `#if 0` block immediately above the restored assembly include. Its layout is represented only by `QuadTreeAllocDraft`, `GeometryAddressesAllocDraft`, `GeometryTableAllocDraft`, and `GeometryLineAllocDraft` inside that block. The natural draft reaches the loop but has a register-allocation mismatch: the first divergent instruction is at function offset 0x06, where the target keeps the line-count bound in r5 while the draft assigns the corresponding values to different registers. Declaration-order, loop-form, width, signedness, pointer, and initializer probes did not remove the cycle.

## sub_805BDBC (0x0805BDBC)

The semantic draft is retained in a `#if 0` block immediately above the restored assembly include. The block contains its own `QuadTreeDraft`, `QuadTreeNodeDraft`, `QuadTreeEntryDraft`, geometry-address, table, spline, point, and line layouts. The original function-level geometry callback declaration is not changed in any header. The draft reaches the node/spline/segment traversal but remains a register/lifetime near miss.

## initQuadTreeNode (0x0805C040)

The semantic draft is retained in a `#if 0` block immediately above the restored assembly include. The block contains its own node, tree, geometry-address, table, point, line, and entry layouts plus `InitQuadTreeCallbackDraft`. The draft callback type is `unk32 (*)(InitGeometryTableDraft*, InitGeometryLineDraft*)`; this is intentionally local to the parked draft because the public header retains the original opaque `unk32` parameter. The draft recovers recursive subdivision and line selection but does not match. The target has a 48-byte frame and incoming-parameter coloring that the natural draft does not reproduce.

## sub_805C9A4 (0x0805C9A4)

A typed semantic experiment was removed after comparison. The target allocates an 84-byte frame; the experiment allocated 68 bytes, diverging at offset 0x0A. The assembly include remains untouched.

## Verification

The active source uses the main-branch header layouts. `cmake --build build --target compare` passes with the restored assembly implementations. The callback parameter refinements explored for `allocQuadTree` and `initQuadTreeNode` remain only as local draft information and are not represented in headers.
