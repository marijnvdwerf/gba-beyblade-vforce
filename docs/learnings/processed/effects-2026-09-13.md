## ProjectileSystem.unk28 is `s16`

`src/ram.h` had `unk16 unk28`. The active test in sub_805529C is a **signed**
halfword load:

```
mov   r1, #0x28
ldsh  r0, [r7, r1]      @ r7 = &_gameData->projectileSystem
cmp   r0, #0
beq   ...
```

`ldsh` with a register offset (Thumb has no immediate form) is positive
evidence for a signed declaration. The decrement in the same function reloads
the field unsigned — `ldrh r0,[r7,#0x28]; sub r0,#1; strh r0,[r7,#0x28]` —
because the result is truncated to 16 bits on store, so agbcc is free to
zero-extend. This is the documented "byte-required mixed access in one
function" case: do not decide the declaration by majority opcode.

## Table index: `(unk8)` truncation, not `& 7`

Target index computation:

```
lsr  r0, #4
lsl  r0, #29
lsr  r0, #23
add  r0, r1             @ r1 = Unk_874CC3C
ldrh r0, [r0]
lsl  r0, #16
asr  r6, r0, #23
```

Step table:

| source form | first divergence |
| --- | --- |
| `Unk_874CC3C[((_unk3000E30[0] >> 4) & 7) * 32] >> 7` | +0x22: emits `mov r1,#7; and r0,r1; lsl r0,#6` (3 insns) instead of `lsl #29; lsr #23` (2 insns); everything after shifts by 2 bytes |
| `Unk_874CC3C[(unk8)((_unk3000E30[0] >> 4) * 32)] >> 7` | none — exact |

The `(unk8)` cast is the byte-typed angle index (256-entry sin table, 8
directions at stride 32). agbcc lowers `(x << 5)` + truncate-to-8 as
`lsl #29; lsr #24`, then folds the array's implicit `* 2` scale into the same
right shift → `lsr #23`. An explicit `& 7` mask materialises the constant
instead and never fuses. This is the SKILL.md rule "keep a measured `(unk8)`
conversion on a derived table index" reproduced verbatim.

The `ldrh; lsl #16; asr #23` load is *not* evidence against `const s16
Unk_874CC3C[]`. Thumb `ldrsh` needs a register offset; when the element
address is already fully materialised in one register, agbcc emits
`ldrh` + `lsl #16` + `asr #(16+N)` for a signed halfword load feeding `>> N`.
Writing the index so the base add lands *before* the load is what selects
this shape; an index whose scaling stays separate produces `ldrsh rd,[rb,ro]`.

## Loop shape

`for (i = 0; i < 3; i++)` over `&_gameData->unk434.records[i]` reproduces the
target's two induction variables without any byte cursor: agbcc strength-reduces
`i * 0x88` into r9 (initialised to the folded `0x434`, `add #0x88` per
iteration) and inserts a separate countdown in r8 (`mov #2`, `add -1`,
`cmp/bge`). `_gameData` is reloaded at the top of each iteration through an
`sl` alias because the `GetBGLayer*OffsetPtr` calls may clobber the global —
that reload is the compiler's, not a source shape.

Register roles landed correctly on the first typed attempt (r8 = count,
r9 = cursor, r10 = `&_gameData`); the earlier report of an r8/r9 swap on the
typed form did not reproduce with a for-body-scoped `record` local.
