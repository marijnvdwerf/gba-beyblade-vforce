## turorial_804A488 (0x0804A488)

`TutorialData.entries` contains 0x20 entries. `initTutorialManagement` stops when `count > 0x1F`, and the flag update is guarded by `index != tutorial->count`; the accessed tutorial-entry index is therefore 0..31 and `index >> 5` is zero. `initCollectables` has the same 0x20-entry cap for its collectable index.

`LevelState.unk10[1]` is the one-word collectable bitset; `sub_8056EC0` accesses it with `[i >> 5]`. `LevelState.unk14[1]` is the one-word tutorial bitset; `turorial_804A488` accesses it with `[index >> 5]`. Both declarations follow the accepted `CollectableData.collectedBits[1]` one-word bitset precedent.

The `s32 index` local is supported by the target `asr r0, r3, #5` at function offset 0x42. The target compares the signed index/count pair with `bge` at 0x24 and `blt` at 0x34, supporting the `s32 count` local.

The exact tutorial source uses direct `levelState->unk14[index >> 5]` access with the mask expression inline. A probe replacing `unk14[1]` with scalar `unk14` (with scalar `unk10` in that probe) first diverged at function offset 0x0A in the non-pool instructions: the game-data base was allocated in `r6` instead of the target's `r7`. The scalar probe was not retained.
