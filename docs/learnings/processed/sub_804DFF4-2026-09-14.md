# sub_804DFF4 (0x0804DFF4, src/riderphysics.c) — matched

Previously parked for the dead entry load `ldr r0, [r5, #0x70]`.

- The load survives only when a later compare of the value is live at `flow`.
  Scratch probes (same flags): `x = rider->unk70;` alone, `(void)`, empty `if`,
  empty `switch`, `?:` and `&& 0` all delete the load. `if (x != 0) x = 0;`,
  `if (x > 5) x = 5;` and `if (x < 0) x = -x;` all keep it (and produce the
  target's `add r5, r0, #0` copy of `rider`): the dead set is removed in flow,
  the compare/branch dies later (jump2), the load stays.
- Shipped `s32 speed = rider->unk70; if (speed < 0) speed = -speed;` — the
  abs form. Byte-required; flagged as a dead-value shape (the value is
  never used). The `s32` is not proven by bytes (the compare vanishes).
- `RiderBase.unk198` → `s32` by `ble` after `cmp r0, #8`; other users are a
  `= 0` store and `++` (unchanged, compare passes).
- `RiderBase.unkD2` (`strb`) and `unk168` (`str`) added.
