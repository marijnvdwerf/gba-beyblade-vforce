## The debugging leftover

The target loads `ldr r6, =_gameData` between `getLevelDescription2()` and
`getLevelMetadata()`, long before its first use, and keeps it in r6. Source:
`gameData = _gameData;` into a local that is never read. Flow deletes the dead
memory load, but the symbol-address pseudo it created survives and is reused by
every later `_gameData->` access. Removing the statement: 9 rows. Actually using
`gameData->` for the first camera access: 23 rows. No scalar alias of a global is
needed.
