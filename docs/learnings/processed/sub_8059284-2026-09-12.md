# sub_8059284

Matched in src/layer.c with the existing BGLayer fields; no header changes.

The disabled draft's `size = mode` initialization was removed. Every possible
mode (the upper two bits of a halfword) assigns size in the switch, and the
affine branch assigns it before returning. The layerReg alias folded away.

With an s32 mode local, the first divergence was at +0xC: the target's
`mov r0, r1` was absent. The function was two bytes shorter and the final two
switch comparisons used r1 instead of r0. Changing only mode to unk16
recovered all instructions, including signed switch dispatch after integer
promotion. Parameters use unk16; no signedness claim is needed.

clang-format followed by `cmake --build build --target compare` passed the
full ROM SHA1 test. No artificial control flow, casts, or layout changes.
