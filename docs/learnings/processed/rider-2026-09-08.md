# sub_804B8F0: plain C match and signedness evidence

## Final status

`sub_804B8F0` at 0x0804B8F0 matches in plain C in `src/rider.c` (0x300 bytes).
The original assembly dump is removed. There are no inline instructions,
barriers, register declarations, volatile matching levers, field-read casts,
extra bare scopes, or matching comments in this implementation.

This supersedes both the invalid match in `ebb47c50` and the parked status in
`1e6be9ca`. The first attempt forced two residuals with banned levers. The
second attempt stopped too early: the residuals have natural C explanations.

## The two decisive fixes

### Collision helper return width

With `sub_805CEB8` declared as returning `unk32`, the caller's accumulation
emits `add r0, r3, r0` at +0x1A6. The target encodes `add r0, r0, r3`.
Rearranging the C addition, introducing result locals, or adjusting their
signedness did not fix this. The missing information was the return width.

| Shared declaration and definition | Caller residual | Callee residual |
| --- | --- | --- |
| `unk32` return | One instruction at +0x1A6 | None |
| `s32` return | One instruction at +0x1A6 | None |
| `unk16` return | None | None |
| `s16` return | None | None |
| `unk8` return | Three rows; first extra normalization at +0x1A4 | None |

The final declaration AND definition use `unk16`. Both halfword signs match,
so signedness is not proven and the project's default type wins. The helper
currently returns zero; its body alone does not distinguish these return
widths. The consuming caller supplies the missing code-generation evidence.
A source search found this as the only C call to `sub_805CEB8`.

This is a concrete case where an apparently harmless commutative register
swap was caused by a prototype, not register allocation. Do not force the
instruction or infer the counter field's sign from operand order.

### Unused angle calculation

The target computes `0x80 - riderBase->unk62` starting at +0x252. A plain dead
assignment is eliminated. However, a normal conditional adjustment:

```c
angle = 0x80 - riderBase->unk62;
if (angle < 0)
    angle = -angle;
```

preserves exactly the target arithmetic after optimization, while the
conditional/negation itself disappears. No retention barrier is needed.
Removing this conditional from the final match produces 29 differing rows;
the first is the shifted literal reference at +0x236, with the absent angle
calculation at +0x252 as the substantive difference.

Single conditional clamp-to-zero, negative-angle wrap by 0x100, upper clamp,
and an absolute-value ternary also preserved the same arithmetic in measured
trials. Therefore the surviving bytes do NOT uniquely establish which
conditional appeared in the original source. The final implementation uses
the straightforward absolute-value form; its result is unused. A two-sided
clamp instead introduced further differences. Earlier claims that all natural
C forms removed the calculation were too broad and are retracted.

## Signedness and shared layout evidence

`unk32` is `u32` and `unk16` is `u16`; the default names do not mean signed.

| Value | Final type / treatment | Evidence and limit |
| --- | --- | --- |
| `RiderBase.unk62` | `s16` | `ldrsh` at 0x0804BB48 directly proves a signed halfword read; subtraction follows at 0x0804BB4C. |
| Loop index | `s32` | Signed `bge`/`blt`. Changing it to `unk32` first diverges at +0x138. The `unk16` count promotes to signed int. |
| Quadtree count | Existing `unk16` | Zero-extended `ldrh` count; no shared change. |
| `RiderBase.unk19C` | `s32`, no field-read cast | Target signed `bgt` against 3 at 0x0804BBAC. All other active users were audited and remain exact. |
| `RiderBase.unk208` | Existing `s32` | Signed `ble` against 0x100. |
| Actor x/y and shifted coordinate temporaries | Existing / local `s32` | Arithmetic shifts by 5 support signed coordinate arithmetic. |
| px/py/pz and new saved-position fields `unk1A8`, `unk1AC`, `unk1B0` | `unk32` | Plain copies do not prove destination signedness. Unsigned locals match exactly. |
| New `unk1B4` | `unk32` | Stored constant 0xFFFC0000 and a coordinate copy establish bits and width, not signedness. |
| New `unk11C` | `unk16` | Halfword stores and zero-extended loads, with low-halfword accumulation. Signed storage can be indistinguishable here; use the default. |
| `sub_805CEB8` return | `unk16` | Caller/callee width trials above; signedness remains indistinguishable. |
| `unk3CC` guard | Existing `unk16`, direct mask expression | Bitmasking does not prove signedness. The separate narrowed flags local folds exactly; no cast is necessary. |
| Effect selector | Existing default unsigned word | `lsr #4`, then mask 3. The masked result alone does not distinguish original source signedness. |

Only actually accessed fields were exposed in existing shared layouts:
Actor +0x3B is a byte store; RiderBase +0x62 is a signed halfword read;
+0x11C is a halfword; +0x1A8/+0x1AC/+0x1B0/+0x1B4 are word accesses.
The original layout sizes/offsets are preserved, as also verified by the ROM.
There are no scratch or duplicate layouts in the final implementation.

Shared `unk19C` audit: searched all source uses. Active users are

(zero store). Each has zero differing rows with the signed declaration.
