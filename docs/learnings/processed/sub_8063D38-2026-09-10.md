Previously parked. Two recovered source shapes:

1. Loop exit is a real `done = 1;` flag, not `break` + never-set flag.
   `while (done == 0) { c = *cursor++; if (c == '}') done = 1; else ... }`
   compiles to the target: CSE jump-following threads the `done = 1` path
   straight past the loop test (`beq` to exit at 0x3C), the store becomes
   dead, and the surviving `mov r5,#0` / `cmp r5,#0; beq` loop test is the
   leftover of the flag. So a "never-cleared" flag register in the target
   is evidence of a flag set only on a path CSE threaded to the exit.

2. Accumulation must be two statements: `value *= 10; value += c - '0';`.
   Measured (diff rows vs target, all else equal):
   - `value = value * 10 - '0' + c;` → 29. Tree fold reassociates it to
     `v*10 + (c - 48)` already in .rtl (insns 116/117); CSE then reuses the
     digit test's `c - 48` and the target's in-place `lsl r0,r0,#24` breaks.
   - `value * 10 + c - '0'` / `c + value*10 - '0'` → 16 ((v*10+c)-48 order).
   - `value * 10 + (c - '0')` / `c - '0' + value*10` → 14.
   - `value = value * 10 - '0'; value += c;` → 4.
   - `value = value * 10; value += c - '0';` → 0. `value *= 10;` → 0.
   - `s32 value` changes nothing; `unk32 character` makes every form worse.
