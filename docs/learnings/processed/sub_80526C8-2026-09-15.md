## Why (measured with asm-annotated .greg)

Priority is `floor_log2(refs) * refs / live_length`. With the nested-if loop,
`current` (refs 20 / live 196 = 0.408) ranked below the first rectangle's right edge
`x` (4 / 17 = 0.471), so `x` took r7 and `current` fell to r8. The early exit's
duplicated `current++` adds 4 weighted refs (24 / 182 → 0.527), so `current` takes
r7 first. Post-reload cross-jumping merges that duplicate increment with the bottom
one, so the code still has a single `add r7, #0xc4`.

The conditional expressions matter too: they reproduce the target's
store-default/compare/overwrite sequence (`lsl r1, r0, #5; str; cmp; bge; lsl r2, #5; str`)
with the target's load order, which the staged temps did not.
