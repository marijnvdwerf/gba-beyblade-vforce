## sub_804703C (0x0804703C, target 68 bytes)

The function remains parked. Its target loads the category byte with `mov r3, #0; ldsb r3, [r1, r3]`, scales it by `0x80`, and indexes eight 16-byte records at `0x080699DC`. The best typed draft uses a 16-byte scratch record and a two-dimensional table expression inside `#if 0`; it is 68 bytes and has the correct signed-byte load, but its address calculation uses a different register/order than the target.

Measured steps:

| Change | Result / first divergence |
| --- | --- |
| Direct scalar offset draft | 72 bytes; target `ldsb`, draft `ldrb; lsl #24; asr #24` at the category load. |
| Signed local and pointer-alias variants | `ldsb` achieved, but the state-byte address was hoisted outside the loop and register/address order diverged before the table load. |
| `s8 unk35[1]` field experiment | No improvement; category load shape remained nonmatching. Reverted to scalar `s8 unk35`. |
| Static/global table-base variants | Extra saved-register/address materialization; table base was cached or hoisted unlike target. Reverted. |
| Typed 16-byte record plus two-dimensional table indexing | 68 bytes and target `ldsb` achieved; first remaining divergence is register allocation/address-calculation order (`r2` versus target `r3`). |
| Declaration, qualifier, and equivalent table-expression variants | No reduction of the remaining register-only divergence. |

The scratch record is intentionally confined to the parked draft. No shared header field was added for it.

## sub_8047080 (0x08047080, target 72 bytes)

Final state: matched exactly with `void sub_8047080(FrontendBladeState* state, unk32 color)`. The source passes `color` directly to `sub_8061E58` and the three `sub_8061130` calls. There are no source shifts and no `shifted` or `loopValue` locals. agbcc lowers the wide argument to the helper's `u8` parameter as the target's `lsl #24` plus per-call `lsr #24`, retaining the shifted value in `r5` and the loop copy in `r6`.

Measured history:

| Change | Result / first divergence |
| --- | --- |
| One transformed local plus loop index | 72 bytes and correct operations, but target roles were swapped: shifted value in candidate `r6`, loop copy in candidate `r5`. |
| Separate `loopValue` and `value` locals with `i = 0; loopValue = arg1 << 24; value = loopValue` | Added `mov r5, r1`; first divergence was the extra parameter reassignment before `lsl`. |

The shifted locals were byte-required only in the rejected transcribed-shift drafts. The three repeated sprite arms have no legal typed loop form without changing the shared `FrontendBladeState` layout to an array and affecting existing callers, so the explicit arms remain.
