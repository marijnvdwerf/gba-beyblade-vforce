## First divergence

The first divergent instruction is the stack allocation at function offset `0x0A`.
The target allocates `0x3C` bytes and keeps the argument in `r5`; the natural
struct-based draft allocates `0x20` to `0x28` bytes depending on the lifetime
variant and keeps the layer pointer in a lower register. The target also retains
separate stack-backed values for the horizontal and vertical base coordinates,
limits, translated map offsets, and callback arguments.
