- Target signed halfword loads prove `unkC`, `unkE`, `unk12`, and `unk14` are signed. The decrement and delay staging still use unsigned halfword loads. A narrow unsigned delay local preserves the latter alongside the signed comparison.

- `UnkTrail.unk28` points to the existing `CameraState`: the caller chain passes `&gameData->unk434`, and the target reads the first background layer's word offsets 0xC and 0x10. No duplicate camera layout is needed.

## Measured source shapes

Initializing `spacing = 0xD00` before the animation loop recovers the target's constant multiplication and later rematerialization. Initializing it after the loop folds the threshold into `0xA9 << 16` and keeps spacing live across calls. Literal products also strength-reduce the vector scaling. Float constant casts did not fix this.

Separate sprite pointer lifetimes for animation and creation were necessary. The final creation phase uses direct `entry->sprite` accesses: caching the sprite adds/reorders moves near function offset 0x1D8. Keeping x/y shared across phases preserves the loop's allocation; scoping both inside each phase substantially changes the loop.

The normalized components are rescaled in place. `angle` must be calculated before that rescaling, so folding its call into the later sprite transform would change its inputs. Reusing the distance local for the square root avoids an additional move. Separate offsetX/offsetY temporaries preserve midpoint arithmetic before loading the previous position.

The positive `if (distanceSquared > spacing * spacing)` and an early-return alternative are byte-identical; retained the positive condition.
