Status: enabled as a user-approved fakematch in `src/riderphysics.c`.

## Evidence and layout

The mainLoop callgraph reaches the function through rider physics; the live C
caller `sub_804D110` passes a RiderBase pointer and ignores the return value.
The assembly call remains present in the caller's surrounding matched code.
The target loads +0x204 and +0x206 with `ldsh`, compares +0x48 and +0x4C using
signed bounds, and compares +0x208 using signed bounds. Thus the candidate needs
s16 fields at +0x204/+0x206 and s32 fields at +0x48/+0x4C/+0x208.
Testing these in the canonical RiderBase layout, plus the existing actor_80580C0
prototype and an actor.h declaration for sub_8058390 matching its definition,
left the entire ROM byte-identical with the experimental candidate enabled.
The canonical header edits are retained for the enabled implementation; the
obsolete scratch struct has been removed.

## Residual and experiments

The original draft is missing the eight instructions at 0x0804D834–0x0804D842:
a category <= 1 / category == 0x400 branch, followed by mov/neg of -1. The -1
is overwritten without being used. Other instruction differences are downstream
literal displacement changes. The natural draft is 16 bytes short.

The exact experimental block is:

```c
if (category <= 1 || category == 0x400) {
    callbackSequence = -1;
    if (callbackSequence != category)
        callbackSequence = category;
}
```

callbackSequence is s32, declared in the enclosing category-change arm and
never consumed. This was constructed to retain the target's dead branch. The
inner comparison has no supported functional purpose, so it is an artificial
matching device, not an established recovery of the original source. No
volatile, inline assembly, compiler flags, or raw-offset accesses were used.
A natural explanation for the dead block remains unresolved. Unrelated loop,
switch-order, and signedness permutations were not applied: the baseline already
matches those regions, and the sole missing operation is the dead conditional.
The residual-analysis file requested by decompiler.md is no longer present at
its top-level path; the prohibited processed archive was not read.

## Temporary folding and final validation

With the exact candidate enabled, folding current changes the first load at
+0xA; folding target changes actor allocation at +0x8; folding actor changes the
prologue at +0x2. Those snapshots remain. Folding value into direct unk208
reads passes the full ROM compare and is retained in the enabled implementation.
The direction, category, and motion locals carry computed state rather than
single-use aliases. Removing the callback calculation returns to the 16-byte
residual described above.

After user approval, the candidate was enabled, the TODO comment added, and
clang-format run on all three touched C/header files. The instruction diff has
no differing rows and `cmake --build build --target compare` passes (1/1
rom-matches tests). The baseline was refreshed after verification. Changes are
left uncommitted in the main checkout.
