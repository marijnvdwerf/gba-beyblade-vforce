# sub_804E594 (0x0804E594, src/particle.c)

Matched with no dead code or leftovers. The work was types plus local shape.

## Types (separate commit, ROM-neutral with the asm build)
- `ParticleSystem.unk6` is `s16`: the target loads it with `mov r3,#6; ldrsh`. The wrap-around test `if (++unk6 >= count)` then lowers to the target's `ldrh; add; strh; lsl #16` plus `ldrh count; lsl #16; cmp; blt`.
- `ParticleSystem.unk10/14/18` and `unk24/28/2C` are `s32`. With `unk32`, `(unk10 - unk24) * (s16)arg1 >> 8` lowers to `lsr #8` instead of the target's `asr #8`. allocateParticleSystem, sub_804E530, sub_804E560, sub_804E584 and sub_804EA88 stay exact after the retype.
- The frame pointer is `&system->unk0->frames[arg5]` (8-byte `SpriteTrailFrame` at `SpriteSheet+0x20`), which gives `arg5 << 3` (as `lsl #16; asr #13`) `+ 0x20 + unk0`. The duplicate `ParticleFrameData` view was removed.

## Shape (grid over order × table local × separate table index × arg5 width × arg1/arg2 locals)
- Byte-required: `particle = &system->particles[system->unk6];` before the table index, and a separate `tableIndex` local. Reusing one index variable for both gave 102 rows.
- Byte-required: direct `word_8074D64[tableIndex + n]` indexing. A `const s16* table` local lets CSE turn `+1`/`+2` into load offsets (83 rows).
- `arg5` is an `s16` parameter. A wide `unk32` with a `(s16)` cast at the use gave 42 rows.
- `arg1`/`arg2` are `s16` parameters. They are byte-identical to wide parameters with `(s16)` casts at the uses, or `s16` locals set at the top or at the use; the normalization still lands at the first use. Kept the cast-free parameter form.
- Byte-required locals: `sprite` (the target spills it to `[sp]` before the writes), `frame`, and `x`/`y`/`z`. Storing `frame->unk0` into the previous sprite instead of `particle->unk1C` also breaks.
- Folded, byte-neutral: the `index = system->unk6` local.
