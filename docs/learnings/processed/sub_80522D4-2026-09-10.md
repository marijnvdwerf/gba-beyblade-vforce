Mechanism notes (agbcc cse.c/thumb.h, read from pret/agbcc):
- Thumb GO_IF_LEGITIMATE_ADDRESS rejects fp/virtual-reg addresses for
  modes < 4 bytes before reload, and BLKmode has size 0 → every access to
  a 12-byte local array/struct forces `reg = fp+off` at expansion.
- find_best_addr returns early for `(plus fp const)`; otherwise ties in
  CSE_ADDRESS_COST go to the higher rtx cost. Thumb RTX_COSTS gives every
  PLUS the same cost, so `(plus P 4)` is never replaced by `(plus fp 64)`
  in the base-replacement loop.
Remaining `(unk32)(delta[0] + 0x1FF) <= 0x3FE` is the sanctioned
signed-range idiom.
