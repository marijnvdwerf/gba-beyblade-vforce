The final instruction diff matched, including the prologue, branch polarity,
frame-store shape, and trailing layout. The dump was deleted after the match.

## sub_804F478 (0x0804F478)

The countdown performs a signed entry test and signed post-decrement test on
`unk104`. The dispatch field is `unk10C`. `LevelHudData.unk106` is declared
`s16`: the target uses signed halfword loads for its clamp and mode extraction,
while the compound update still emits the target unsigned halfword load,
addition, and store before signed normalization.

The exact source shape retains an `s16 value` temporary for the two case-3
clamp checks and for the countdown threshold check. Replacing it with direct
field expressions was measured in `/tmp/f478-notemp-diff.log`: the body then
became four bytes shorter, emitted an unsigned `bhi` instead of the target's
signed `bgt` for the `unk104 <= 0x3B` test, and shifted the literal pool and
cleanup tail. The temporary is therefore retained as the natural source shape
required by the exact build.

The case-3 coordinate update uses `unkF4->unk8`, with the subtraction ordered
before adding `(unk106 << 4)`:

```c
((state->unkF4->unk8 & 0xFFFFFF00) - 0x800) + (state->unk106 << 4)
```

The case-2 updates use the same base object and the target offsets/constants.
The switch's active path ends with an explicit `return`; this keeps the common
cleanup tail reachable only after the initial or decremented countdown reaches
zero. The cleanup tests `flags & 8` and calls `sub_804F794` with the containing
`LevelHudData*` pointer.

The final instruction diff matched exactly. The target and current function
size are both `0x31C`, with the literal pool at relative `0x2F0`, the cleanup
tail at `0x300`, and the epilogue at `0x316`. No union or storage pun was
needed. The dump was deleted after the match.
