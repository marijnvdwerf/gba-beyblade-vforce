# levelrow matching notes — 2026-09-17

## sub_804A26C (0x0804A26C)

- The function has no parameters and clears bit 13 of the GBA display-control register with `*(vu16*)REG_DISPCNT &= ~DISP_WIN0_ON`; `DISP_WIN0_ON` is `0x2000` in the SDK, yielding the target `0xDFFF` mask.
- The direct volatile halfword register access emits the target address construction, `ldrh`, mask, `strh`, and return exactly. Both `<agb/define.h>` and `<agb/memory_map.h>` are required.
- `bun run tools/diff/diff.ts sub_804A26C` reports every instruction equal.

## sub_804A1E4 (0x0804A1E4)

- The function takes `SpriteTextCleanup*` and computes a one-row window from the text bounds: `sub_8061E44` supplies the top coordinate, `sub_8061D54` the left coordinate, and `sub_8061E08` the right coordinate. The target arithmetic requires signed `s32` locals shifted after assignment (`asr #8`), with a separate `bottom = top + 8` value retained for the vertical register.
- `REG_WIN0H` is written as `(left << 8) + (right + 1)` and `REG_WIN0V` as `(top << 8) | bottom`; the SDK register names and `vu16` accesses match all instructions.
- Folding `top`, `left`, and `right` shifts into their assignments changed the target `asr #8` instructions to `lsr #8` at offsets `0x0E`, `0x1E`, and `0x26`, so separate signed shift statements are required.
- Dropping `bottom` and writing `(top << 8) | (top + 8)` changed the prologue and register allocation, so the separate `bottom` staging is required.
- `bun run tools/diff/diff.ts sub_804A1E4` reports every instruction equal.
