### 2026-09-18 — `maskGreen`/`maskBlue` retracted; lever-free form found

The earlier "`maskGreen` and `maskBlue` are byte-required" conclusion is retracted.
It held only while the `s32 offset` staging local was also present; the three
locals had to be removed **together**.

- agbcc hoists `0x3E0` and `0x7C00` into `r9`/`r8` (`mov #248` + `lsl #2` / `lsl #7`)
  by itself — the literal temps never changed *what* was emitted, only *where*.
  Replacing them with inline literals while keeping `s32 offset` produced the
  same 180 bytes with only the preheader block order permuted: first divergence
  at preheader slot 6, `lsl r2, #16` (the `offset = offsetInput` sign extension)
  emitted before `mov r1, #248` instead of between the two mask setups.
- The preheader emits user assignments in source order first, then loop-invariant
  hoists in order of first use inside the loop. The target order is
  `i = 0`, greenMask, offset sign-extension, blueMask — i.e. the offset
  conversion is itself a *hoist*, not a user statement. So `offset` must not be a
  local at all: the `s16` parameter is used directly in the loop, and its
  widening is hoisted between the two mask hoists because the loop body's first
  uses run `0x3E0` (green extract), then `offset` (`red += offset`), then
  `0x7C00`… the hoister orders by the invariant's position in the RTL loop after
  scheduling, which lands offset between the masks.
- Byte-identical forms measured (all with inline `0x3E0`/`0x7C00`, no `offset` local,
  `s16 offset` parameter used directly): `do { … i++; } while (i < 8)`,
  `while (i < 8) { … i++; }`, `for (i = 0; i < 8; i++)`, and the variant keeping a
  local re-declared `s16 offset = offsetInput`. Also byte-identical:
  `BG_PLTT + paletteIndex * 0x200` for the destination. The `for` form is shipped.
- Measured non-matches (first divergence): fusing extraction and add
  (`red = (color & 0x1F) + offset;`) → 178 bytes, diverges at preheader slot 6;
  `else if` clamps → same size, `ble` displacement differs at `+0x54`;
  `|` instead of `+` when recombining → `orrs` at `+0x8C`; `src[i]`/`dst[i]`
  indexing → 186 bytes, needs `sl`; `(color >> 5) & 0x1F` shift-then-mask →
  164 bytes (masks stop being hoisted); `s32 red/green/blue` → 132 bytes;
  `unk32 color` → 156 bytes; `s32 i` → 178 bytes; `unk32 i` → 176 bytes;
  dropping the `color` local and re-reading `*src` → 176 bytes.
- `color` (`unk16`), `i` (`unk16`) and the three `s16` channels are byte-required
  temps. `red/green/blue` are proven `s16` by the `asr #16` sign extensions before
  each `cmp #31` / `cmp #0`; `i` is proven 16-bit unsigned by `lsl #16` / `lsr #16`
  and `bls`; the `offset` parameter is proven `s16` by `lsl r2, #16` / `asr r5, #16`.
- US ROM compare green after the rewrite: SHA1 `cd527c8c24e20e33913fc45199e64b3e6138a6e5`.
