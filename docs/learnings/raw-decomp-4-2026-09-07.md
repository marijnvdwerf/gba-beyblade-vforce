  (`unk11_3`); `allocateDynamicBoundingAreas` and `initQuadTreeNode` both

  from `gameLoop`; the function retains only relocation-display differences

  teletype, effects, results, and beyblade APIs. `TeletypeState` remains an

  riderphysics object size.

  metadata fields are signed halfwords and the target emits `ldrsh` before the
  helper call. The helper stores remain halfword fields and its direct diff is

  target `ldrh`/`orr`/`strh` initialization with source `|= -1`, and removing
  the dead `timer` staging from `gameLoop` is instruction-identical.
- The requested temporary-folding trials were performed independently for
  each matched function. Every retained alias is backed by a measured first

- In `sub_804E090`, removing the final `(unk16)` cast before `& 0xFF`

## Group 6 signedness review

- `sub_804D110` retains `s8 oldDirection`. The target loads `rider->unk8` with
  `ldrb` at function offset `+0x10`, saves it in `r9`, and later emits
  `lsl #24` followed by `asr #24` before comparing it with the newly computed
  direction at offsets `+0x350` and `+0x352`. Changing only the local to
  `unk8` removes that sign normalization, changes the comparison register
  shape, and shrinks the function from `0x600` to `0x5FC` bytes. The signed
  local is therefore required by codegen and matches exactly.
- `gameLoop` retains `s8 fadeStep`, `s8 fadeDir`, and `s8 vblankPending`.
  `fadeStep` is proven signed by the `fadeStep < 0` clamp; changing it to
  `unk8` is rejected by the compiler because the comparison is always false.
  The target sign-extends both `fadeStep` and `fadeDir` before their addition
  at offsets `+0x3EE` through `+0x3F6`; changing only `fadeDir` to `unk8`
  removes those conversions, changes the arithmetic order/registers, and
  shrinks `gameLoop` from `0x7DC` to `0x7D4`. Changing only `vblankPending` to
  `unk8` changes later byte normalization and shrinks the function to `0x7D8`.
  The three signed locals are retained and the final function diff is exact.

| Signedness trial | Result |
| --- | --- |
| `sub_804D110.oldDirection: s8 -> unk8` | Rejected; target sign extension disappears and size changes `0x600 -> 0x5FC` |
| `gameLoop.fadeStep: s8 -> unk8` | Rejected by `-Werror`; `fadeStep < 0` becomes an always-false comparison |
| `gameLoop.fadeDir: s8 -> unk8` | Rejected; sign-extension/addition region diverges and size changes `0x7DC -> 0x7D4` |
| `gameLoop.vblankPending: s8 -> unk8` | Rejected; byte normalization and downstream layout diverge, size changes `0x7DC -> 0x7D8` |
