## `sub_805A148` (`0x805A148`)

- Exact code generation uses `s32 *` for all three quaternion parameters and the return value. With `unk32 *` parameters, the first arithmetic shift diverges as `lsr #8` instead of the target `asr #8`.
- The natural component names are `x = a[0]`, `y = a[1]`, `z = a[2]`, and `w = a[3]`. The target schedule requires separate interleaved loads in the order `y`, `z`, `w`, `x` while forming the first output.
- `out0` is a byte-required accumulator. Its product sequence is `b[2] * y`, subtract `z * b[1]`, add `b[0] * w`, and add `b[3] * x`; this reproduces the target's interleaved load and multiply schedule without an assignment expression in an input load.
- The accumulators for outputs 1 through 3 fold into their final assignments byte-identically. The resulting expressions retain the target product order.
- The measured all-loads-up-front form with `x = a[0]`, `y = a[1]`, `z = a[2]`, `w = a[3]` and four single-expression output assignments diverged at `0x06`: it emitted `ldr r5, [r0, #0]` where the target begins with `ldr r6, [r0, #4]`.
- A separate test kept the component loads as `y = a[1]`, `z = a[2]`, `w = a[3]`, `x = a[0]` and folded `out0` into the first single-expression assignment. It diverged at `0x08`: the test emitted `ldr r3, [r0, #8]` where the target loads `ldr r3, [r1, #8]`. The staged `out0` form is therefore byte-required.
