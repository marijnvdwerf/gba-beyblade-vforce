# sub_8757CD0

Matched in `src/iwram.c`; ARM IWRAM ISR at 0x08757CD0 (84 bytes), installed through `_unk3000DF0[6]`. Full ROM compare passed.

It performs a halfword post-increment load from `unk3C`, writes `REG_SIOMLT_SEND`, sets bit 7 in `REG_SIOCNT`, stores the incremented cursor back to `unk3C`, then increments `unk0`.
