# camera matching notes — 2026-09-17

## sub_805EEA4 (0x0805EEA4)

- The exact signature is `s16 sub_805EEA4(const ScreenLayout*, unk16, s16)`.
- The first parameter walks fixed-stride 0x84-byte `ScreenLayout` records and reads the `unk0` word at offset 0.
- `s16 i` is required for the target signed `bge`/`blt` tests and the target `lsl`/`lsr`/`asr` increment sequence. An `unk32 i` changes the entry test to unsigned `bhs` and reduces the increment to `add #1`.
- Typed `records++` on the 0x84-byte `ScreenLayout` produces the target `add r4, #132`; using the existing 0x88-byte `BGLayer` stride diverges.
- The target and current function instructions are identical under `bun run tools/diff/diff.ts sub_805EEA4`; the full US ROM compare passes.
